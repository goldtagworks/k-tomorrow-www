# Korean Copywriting — 공공기관 톤앤매너 카피라이팅

## 워크플로우

1. **톤앤매너 정의** — 공공기관 LMS에 적합한 카피 톤
   - 담백하고 구체적: 과장 없이 실제 기능과 수치를 명시
   - 포용적이고 따뜻한: 시니어·외국인을 환영하는 어조
   - 전문적이지만 쉬운: 기술 용어를 일반인이 이해할 수 있게 풀어서
   - **금지 표현**: "혁신적인", "획기적인", "차세대", "최첨단", "AI 기반" (과장)
   - **권장 표현**: 구체적 수치 ("14개 언어", "6단계 역할 관리", "3개 독립 포털")

2. **Hero 카피 작성**
   - 헤드라인: 핵심 가치 제안 (1줄, 15자 이내 권장)
   - 서브헤드라인: 구체적 설명 (2줄, 40자 이내)
   - 예시 방향:
     - "모두를 위한 디지털 배움터"
     - "14개 언어로 배우는, 누구나 쉬운 교육 플랫폼"

3. **Feature 카피 작성** — LMS 핵심 기능 5~6개
   - 각 기능: 제목 (4~8자) + 설명 (20~30자)
   - k-tomorrow LMS의 실제 기능 기반:
     - 다중 기관 관리 (3Depth 기관 트리)
     - 6단계 역할 기반 접근 제어
     - 3개 독립 포털 (관리자/강사/수강생)
     - 14개 언어 지원
     - 자동화 파이프라인 (회의록 수집, 녹화 업로드)
     - 실시간 화상 수업 (Google Meet 연동)

4. **Trust 카피 작성** — 신뢰 요소 콘텐츠
   - 실적 카운터: 유기적 수치 사용 (라운드 넘버 금지)
     - 예: "47개 기관 도입", "14개 언어 지원", "98.7% 가동률"
   - 기관 담당자 추천사 (3~4개):
     - 현실적 이름 + 직함 + 기관명
     - 한국 공공기관 맥락에 맞는 직함 (교육과장, 센터장, 프로그램 담당자)
     - 추천사 내용: 구체적 효과를 언급 ("출석 관리 시간이 절반으로 줄었습니다")

5. **CTA 카피 작성**
   - Primary: "도입 문의하기", "상담 신청하기"
   - Secondary: "제안서 받기", "소개자료 다운로드"
   - Tertiary: "무료 데모 체험", "3분 둘러보기"

6. **Accessibility Showcase 카피** — 14개 언어 + 시니어 모드 소개
   - 14개 언어를 시각적으로 표현하는 카피
   - 시니어 모드의 가치를 설명하는 카피
   - "누구도 소외되지 않는 교육"

7. **Footer 카피**
   - 이메일, 전화번호 (공공기관 필수)
   - 저작권, 개인정보처리방침
   - 관련 기관 명시
