# Accessibility Audit — WCAG 2.2 AA + 시니어 모드 검증

## 워크플로우

1. **WCAG 2.2 AA 핵심 기준 검증**

   ### 인식의 용이성 (Perceivable)
   - [ ] 1.1.1 텍스트가 아닌 콘텐츠: 모든 이미지에 의미 있는 `alt` 속성
   - [ ] 1.3.1 정보와 관계: 시맨틱 HTML 사용 (heading 계층, 랜드마크)
   - [ ] 1.3.5 입력 목적 식별: 폼 필드에 `autocomplete` 속성
   - [ ] 1.4.3 대비 (최소): 일반 텍스트 4.5:1, 대형 텍스트 3:1
   - [ ] 1.4.4 텍스트 크기 조절: 200%까지 확대 시 콘텐츠 손실 없음
   - [ ] 1.4.10 리플로우: 320px 뷰포트에서 가로 스크롤 없음
   - [ ] 1.4.11 비텍스트 대비: UI 컴포넌트 대비 3:1
   - [ ] 1.4.12 텍스트 간격: 사용자 정의 텍스트 간격 시 콘텐츠 손실 없음

   ### 운용의 용이성 (Operable)
   - [ ] 2.1.1 키보드: 모든 기능 키보드로 접근 가능
   - [ ] 2.1.2 키보드 트랩 없음: Tab 키로 모든 요소 순회 가능
   - [ ] 2.4.1 블록 건너뛰기: Skip Navigation 링크 존재
   - [ ] 2.4.2 페이지 제목: 의미 있는 `<title>` 태그
   - [ ] 2.4.3 포커스 순서: 논리적 탭 순서
   - [ ] 2.4.6 제목과 레이블: heading이 내용을 설명
   - [ ] 2.4.7 포커스 표시: `:focus-visible` 스타일 명확
   - [ ] 2.5.5 터치 타겟 크기: 최소 44×44px (시니어 모드: 56×56px)

   ### 이해의 용이성 (Understandable)
   - [ ] 3.1.1 페이지 언어: `<html lang="ko">`
   - [ ] 3.1.2 부분 언어: 다른 언어 텍스트에 `lang` 속성
   - [ ] 3.2.1 포커스 시: 예기치 않은 맥락 변화 없음
   - [ ] 3.2.3 일관된 네비게이션: 모든 섹션에서 일관된 네비게이션
   - [ ] 3.3.2 레이블 또는 지시문: 폼에 적절한 레이블

   ### 견고성 (Robust)
   - [ ] 4.1.2 이름, 역할, 값: ARIA 속성 올바른 사용
   - [ ] 4.1.3 상태 메시지: 동적 콘텐츠에 `aria-live` 영역

2. **시니어 모드 전용 검증**
   - [ ] `data-mode="senior"` 토글 시 모든 CSS 변수가 올바르게 전환
   - [ ] 시니어 모드 글꼴 크기: 본문 ≥ 20px, 헤드라인 ≥ 28px
   - [ ] 시니어 모드 버튼 크기: ≥ 56×56px 터치 타겟
   - [ ] 시니어 모드 대비비: AAA 수준 (7:1)
   - [ ] 시니어 모드 설정이 localStorage에 저장되어 재방문 시 유지
   - [ ] 시니어 모드 전환 버튼이 접근하기 쉬운 위치에 있음

3. **스크린리더 호환성 검증**
   - [ ] heading 계층 올바름 (h1 1개, h2 → h3 순서)
   - [ ] 이미지 alt 텍스트가 의미 있음 (장식 이미지: `alt=""`)
   - [ ] 링크 텍스트가 목적지를 설명 ("여기를 클릭" 금지)
   - [ ] 폼 요소에 `<label>` 연결
   - [ ] 모달/드롭다운에 `aria-expanded`, `aria-haspopup` 속성
   - [ ] 동적 콘텐츠 변경 시 `aria-live` 알림

4. **14개 언어 UI 접근성**
   - [ ] 언어 선택 드롭다운에 `aria-label="언어 선택"` 존재
   - [ ] 각 언어 옵션에 `lang` 속성 (예: `<option lang="vi">Tiếng Việt</option>`)
   - [ ] 키보드로 언어 선택 가능

5. **감사 리포트 작성**

## 도구 사용법

- `Read`: index.html 읽어서 전체 분석
- `Grep`: 접근성 관련 속성 검색 (alt=, aria-, role=, lang= 등)
- `Write`: 감사 리포트를 docs/ 디렉토리에 저장

## 출력 규칙

- 산출물: `docs/accessibility-audit-report.md`
- WCAG 기준 번호와 함께 이슈 기록
- 이슈 형식:
  ```
  ## [P0] WCAG 1.4.3 — 대비 부족
  - 위치: .hero-subtitle (line 45)
  - 현재: #999999 on #FFFFFF = 2.85:1
  - 수정 지시: #999999 → #595959 (대비비 7.01:1)
  ```
- 심각도: P0 (WCAG A 위반) / P1 (WCAG AA 위반) / P2 (WCAG AAA 미달) / P3 (모범 사례)
- 접근성 점수: 0~100 (통과한 기준 수 / 전체 기준 수)

## 에러 처리

- HTML 파일이 아직 없는 경우: 디자인 문서·컴포넌트 스펙 기반 사전 검증
- 대비비 계산 도구 없는 경우: HEX 값으로 수동 대비비 계산 (상대 휘도 공식 적용)
