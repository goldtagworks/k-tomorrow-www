# UX Strategy — 접근성 퍼스트 UX 전략

## 워크플로우

1. **타겟 유저 시나리오 정의** — 3개 퍼소나의 사이트 방문 시나리오
   - **기관 의사결정자** (B2G): "우리 기관에 적합한 LMS인지 30초 안에 판단하고 싶다"
   - **시니어 학습자**: "내가 쓸 수 있는 쉬운 교육 사이트인지 확인하고 싶다"
   - **외국인 학습자**: "내 언어로 볼 수 있는지, 어떤 과정이 있는지 알고 싶다"

2. **페이지 구조 맵 설계** — 필수 섹션 순서 (최소 8개)
   - Navigation (단순 1단 + 시니어 모드 토글 + 언어 선택)
   - Hero (가치 제안 + 인터랙티브 데모 프리뷰 or 시각적 요소)
   - Trust Strip (도입 기관 로고 월 + 실적 카운터)
   - Features (LMS 핵심 기능 — Bento Grid 또는 Zig-Zag)
   - Accessibility Showcase (14개 언어 + 시니어 모드 시각적 데모)
   - Testimonials (기관 담당자 추천사)
   - CTA Section (도입 문의 + 제안서 + 데모 3단 경로)
   - Footer (연락처 + 인증마크 + 관련 기관)

3. **유저 플로우 매핑** — 각 퍼소나별 시선 흐름
   - 기관 의사결정자: Hero → Trust Strip → Features → CTA (빠른 전환)
   - 시니어 학습자: Hero → Accessibility Showcase → Features (기능 이해)
   - 외국인 학습자: Navigation(언어 전환) → Hero → Accessibility Showcase

4. **스크롤 경험 설계**
   - 인접 섹션은 반드시 다른 레이아웃 패턴 사용
   - 섹션 전환 리듬: 밝은↔어두운, 넓은↔좁은, 텍스트 중심↔비주얼 중심
   - 아크 모티프를 섹션 구분자로 활용

5. **네비게이션 전략**
   - 데스크톱: 단순 1단 네비 (5개 이하 메뉴)
   - 모바일: 풀스크린 오버레이 메뉴 (큰 터치 타겟)
   - 스크롤 시 Floating Navigation (현재 섹션 표시)
   - 메뉴 깊이 ≤ 2단계 (시니어·외국인 배려)

## 에러 처리

- 크리에이티브 브리프가 아직 없는 경우: 벤치마크 리포트와 LMS 소개 문서 기반으로 독립 설계
- 섹션 수가 8개 미만인 경우: 최소 섹션 요구사항 충족 필요 — 부족한 섹션 추가
