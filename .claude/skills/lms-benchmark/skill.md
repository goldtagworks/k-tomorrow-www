# LMS Benchmark — 교육/공공기관 사이트 벤치마킹

## 워크플로우

### 1. 분석 대상 선정
사용자 요청에 따라 분석 카테고리를 결정한다:

**국내 교육 플랫폼 (B2B/B2G 홍보 사이트)**
- 엘리스, 구름에듀, 클래스팅, 에듀윌 B2B
- 포인트: 기관 도입 유도를 위한 CTA, 실적 제시 방식

**공공 교육 플랫폼**
- 국가평생교육진흥원(늘배움), K-MOOC, 디지털배움터
- 포인트: 공공기관 디자인 관행, 인증마크, 접근성

**다문화/사회통합 기관**
- 다문화가족지원포털, SOCINET, 지역 다문화가족지원센터
- 포인트: 다국어 UI, 대상별 콘텐츠 분리, 신뢰 요소

**해외 교육 공공 사이트**
- Canvas LMS, Moodle, GOV.UK 교육, Coursera for Government
- 포인트: 글로벌 디자인 표준, 접근성 모범 사례

### 2. 사이트별 분석 수행
각 사이트에 대해 WebFetch 또는 WebSearch를 사용하여 다음을 분석:

```
분석 템플릿:
─────────────
사이트명:
URL:
카테고리:

[히어로 섹션]
- 첫 화면 구성 요소:
- 브랜드 존재감 (1-5):
- CTA 문구 & 배치:

[컬러]
- 주색:
- 보조색:
- 배경 처리:

[타이포그래피]
- 헤딩 서체:
- 본문 서체:
- 크기 체계:

[신뢰 요소]
- 인증/수상 마크:
- 실적 수치:
- 파트너/고객 로고:
- 후기/사례:

[접근성]
- 글꼴 최소 크기:
- 다국어 지원:
- 모바일 대응:

[핵심 인사이트]
- K-Tomorrow에 적용할 점:
- 피해야 할 점:
```

### 3. 패턴 종합
개별 분석을 종합하여 공통 패턴을 도출:

- **신뢰 패턴**: 공공기관 사이트에서 반복되는 신뢰 요소
- **컬러 패턴**: 교육/공공 분야에서 선호되는 색상 계열
- **레이아웃 패턴**: 히어로, 기능 소개, CTA 배치의 공통 구조
- **접근성 패턴**: 시니어/외국인 대상 사이트의 UX 특징

### 4. 디자인 방향 제안
분석 결과를 바탕으로 K-Tomorrow 사이트의 디자인 방향을 제안:

- 추천 컬러 방향
- 추천 서체 방향
- 히어로 구성 제안
- 필수 신뢰 요소 목록
- 섹션 구성 제안

## 도구 사용법
- **WebSearch**: 사이트 검색, 디자인 트렌드 검색
- **WebFetch**: 실제 사이트 접근하여 구조 분석
- **Write**: 분석 결과를 `docs/benchmark-report.md`에 저장
- **Read**: 기존 프로젝트 파일 참조 (backup/index.html, site.css 등)

## 출력 규칙
- 산출물: `docs/benchmark-report.md`
- 형식: 마크다운, 사이트별 분석 + 종합 패턴 + 디자인 방향 제안
- 최소 5개 이상의 사이트 분석 포함
- 각 인사이트에 "왜 K-Tomorrow에 적용해야 하는가" 이유 포함

## 에러 처리
- 사이트 접근 불가 시: 캐시된 정보나 대체 소스 활용, 분석 불가 사이트는 명시
- 정보 부족 시: 해당 항목 "분석 불가 — 이유" 기재, 유사 사이트로 대체
